# Requirements: プログラミング英単語学習アプリ

## 概要

プログラミングに必要な英単語を効率よく学習するための個人用Webアプリ。
フラッシュカード形式とクイズ形式の2つの学習モードを提供する。

## 対象ユーザー

- 自分専用（シングルユーザー）

## 技術スタック

- **フロントエンド**: Vite + React + TypeScript
- **データ**: ローカルJSONファイル（単語データ）
- **永続化**: localStorage（学習進捗）
- **スタイリング**: CSS Modules or Tailwind CSS（TBD in design）

## 機能要件

### FR-1: 単語データ管理

- FR-1.1: JSONファイルに単語データを定義する
- FR-1.2: 各単語は以下の情報を持つ
  - 英単語（例: `refactor`, `deprecate`, `assertion`）
  - 日本語の意味
  - プログラミングにおける使用例（コードスニペットまたは文脈）
  - カテゴリ（技術領域別）
  - 難易度（初級 / 中級 / 上級）
- FR-1.3: 技術領域カテゴリ:
  - 基本構文（変数、関数、制御構文関連）
  - データ構造・アルゴリズム
  - Git / バージョン管理
  - API / HTTP
  - データベース
  - エラーハンドリング / デバッグ
  - 設計パターン / アーキテクチャ
  - テスト
  - DevOps / インフラ
  - コードレビュー / コラボレーション

### FR-2: フラッシュカードモード

- FR-2.1: 英単語を表面に表示し、タップ/クリックで裏面（意味＋使用例）を表示
- FR-2.2: カードをめくった後「覚えた」「まだ」の2択で自己評価
- FR-2.3: カテゴリ・難易度でフィルタリングして学習可能
- FR-2.4: スワイプまたはボタンで次のカードに進む

### FR-3: クイズモード

- FR-3.1: 4択問題（英単語→日本語の意味を選択）
- FR-3.2: 4択問題（日本語の意味→英単語を選択）
- FR-3.3: タイピング問題（日本語の意味を見て英単語を入力）
- FR-3.4: クイズ終了後に正答率と間違えた単語の一覧を表示
- FR-3.5: 出題数を選択可能（10問 / 20問 / 全問）
- FR-3.6: カテゴリ・難易度でフィルタリングして出題可能

### FR-4: 学習進捗管理

- FR-4.1: 各単語の学習状態をlocalStorageに保存
  - 未学習 / 学習中 / 習得済み
- FR-4.2: フラッシュカードの「覚えた」「まだ」の結果を記録
- FR-4.3: クイズの正答/誤答履歴を記録
- FR-4.4: 間違えた単語を優先的に出題する「苦手克服モード」
- FR-4.5: 全体の進捗をダッシュボードで表示
  - カテゴリ別の習得率
  - 難易度別の習得率
  - 総学習単語数 / 習得済み単語数

### FR-5: ナビゲーション

- FR-5.1: ホーム画面から各モード（フラッシュカード / クイズ / ダッシュボード）にアクセス
- FR-5.2: カテゴリ一覧・単語一覧を閲覧可能
- FR-5.3: 単語の検索機能

## 非機能要件

### NFR-1: パフォーマンス

- 初回ロードは3秒以内
- 画面遷移はインスタント（SPA）

### NFR-2: レスポンシブ

- PC・スマホ両方で使用可能
- スマホでの操作（スワイプ等）に対応

### NFR-3: オフライン対応

- データはすべてローカルなので、ビルド後はオフラインで動作可能

### NFR-4: データの拡張性

- JSONファイルに単語を追加するだけで新しい単語を学習対象にできる

## スコープ外

- ユーザー認証
- クラウド同期
- 複数ユーザー対応
- 管理画面からの単語編集機能（JSONを直接編集する）
- スペースド・リピティション（間隔反復）アルゴリズム（V2で検討）
